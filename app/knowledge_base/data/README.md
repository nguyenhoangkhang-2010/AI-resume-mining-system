# Knowledge Base Data

This directory stores external taxonomy datasets.

Examples:

- ESCO
- O*NET
- Certifications
- Industry mappings

Large datasets should not be hardcoded in Python code.

## O*NET

Place downloaded O*NET database files under

data/onet/raw/

Expected files

- Occupation Data.csv
- Job Titles.csv
- Essential Skills.csv
- Transferable Skills.csv
- Knowledge.csv
